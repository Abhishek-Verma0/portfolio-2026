# Abhishek Verma — Portfolio 2026

An developer portfolio featuring a **Cyber-Noir** aesthetic. Built with  Next.js, and Framer Motion, this site is designed to showcase engineering expertise with a sophisticated, creative-agency-level visual experience.

## ✨ Key Features

- **High-Impact Aesthetics**: Deep obsidian theme with dynamic mesh gradients and holographic glassmorphism.
- **Interactive Orbit Visual**: Advanced avatar orbital system with floating tech badges (React, Next.js, SQL, etc.).
- **Smooth Animations**: Section-based reveal animations and fluid hover states powered by Framer Motion.
- **Multilingual Preloader**: A retro-modern localized "Hello" animation for global accessibility.
- **Responsive Design**: Fully optimized for every device, from mobile to ultra-wide displays.
- **Performance Focused**: Minimal dependencies and optimized asset loading.

## 🛠️ Technical Stack

- **Framework**: Next.js (App Router)
- **Styling**: Vanilla CSS with Design Tokens
- **Animations**: Framer Motion
- **Fonts**: Outfit (Headings), Inter (Body)
- **Images**: ImageKit.io CDN integration

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Abhishek-Verma0/portfolio-2026.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000)
